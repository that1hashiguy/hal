Browser trust check

Click Chrome's site information icon, open Connection is secure and Certificate is valid, then inspect the subject, DNS SAN, issuer, chain and fingerprint. Check the hostname in the address bar. This page cannot read Chrome's trust decision or diagnose a handshake that failed before it loaded.

These are private Vault roots. Trust them explicitly using the instructions in docs/commands/vault-pki.md. The ML-DSA-65 certificate modes are separate from the workload mTLS demo and do not imply public trust.
